Как добавить: на GitHub откройте репозиторий -> Add file -> Upload files, перетащите PNG
в папку assets/clubs (при загрузке укажите путь assets/clubs/ в имени или создайте папки)
-> Commit changes.
Либо загрузите эмблему прямо в игре: Карьера -> нажмите на эмблему своего клуба.
