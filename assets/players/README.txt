ФОТОГРАФИИ ИГРОКОВ
===================
Для каждого клуба есть своя папка (имя папки = id клуба, список ниже).
Фото игрока кладёте в папку его клуба. Имя файла: фамилия-имя латиницей, строчными буквами,
расширение .jpg или .png. Пример: assets/players/cska/mamin-maksim.jpg

Когда я соберу составы клубов, я дам точный список имён файлов для каждого клуба
(чтобы ничего не придумывать самим). Если фото нет, игра покажет силуэт.

Рекомендации к фото: портрет, примерно квадратный кадр (лицо по центру), 300x300 пикселей,
до 100 КБ на файл.

Как загружать: на GitHub откройте нужную папку клуба -> Add file -> Upload files ->
перетащите фото (за один раз до 100 файлов) -> Commit changes.
